# Automatic covers for new books

Open a new book and Talevoxa now looks for a cover in the background if embedded artwork is missing. No need to click Find missing covers each time. Reading can start while the search runs.

Automatic lookup is on by default. It sends the new book title to Open Library, never the book file or reading history. Turn it off using Covers > Find covers automatically for new books; your choice is remembered, and switching it off cancels pending automatic searches.

Existing and manually chosen covers are kept. Exact title matches with one known author are saved locally for offline use; editions may differ. Uncertain matches and connection errors leave the fallback cover in place, without interrupting reading. Find online and Find missing covers remain available for manual review and retries.

Only newly added books are searched automatically. Reopening an existing book does not trigger another search, and updating the app does not send your existing library for lookup.

Use Check for updates in Talevoxa to install this Windows preview.
