A FEW GOOD QUESTIONS

Before you settle in.

Is it really free?

Yes. Quiet Pages is free and open source. It uses free Kokoro voices, with no subscription or per-book listening fees.

Does it work without the internet?

Yes, after the first voice download of about 350 MB. Speech is generated on your computer, and your book text is not sent to a server.

Which books can I open?

Word (.docx) documents, DRM-free EPUBs, text or scanned PDFs, and TXT files. Save older .doc files as .docx first. Scanned pages use offline OCR, which can make mistakes. Some complex PDF layouts may read out of order.

Why might Windows show a warning?

This early preview is not digitally signed, so Windows may show an unknown-publisher message. Download only from the linked official GitHub repository and inspect the source if you want to review it.

Can I use it on Mac or my phone?

This version is for 64-bit Windows PCs. Mac, mobile and Windows ARM support have not been validated.

How do I hear about new features?

Announcements appear here when a new GitHub release is published. For notifications, use GitHub’s Watch → Custom → Releases setting, or subscribe to the release feed in your RSS reader.

A note from the first chapter: this is an early preview. Automated import and build checks have passed; we’re still gathering real-world listening feedback. Tell us how it goes.
